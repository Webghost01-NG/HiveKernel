## 📌 The Core Problem: The Machine-to-Machine Trust Deficit

In decentralized multi-agent swarms, monolithic AI agents fail on complex multi-stage engineering tasks. True swarm intelligence requires **subcontracting**—specialized agents outsourcing subtasks (e.g. smart contract vulnerability auditing, oracle verification, on-chain arbitrage modeling, data scraping) to peer agents in the network.

However, existing frameworks suffer from critical flaws:
1. **The Machine-to-Machine Trust Deficit**: If Agent $A$ hires Agent $B$, how does Agent $A$ verify that Agent $B$ did not hallucinate, fake the computation, or omit vulnerabilities?
2. **Subjective Output Incompatibility**: Smart contracts cannot natively parse natural language or analytical outputs generated by LLMs.
3. **Absence of Autonomous Non-Custodial Escrow**: Agents lack peer-to-peer escrow rails that allow instant micro-settlement and dispute slashing without human intervention.

## 🏛️ System Architecture

HiveKernel is organized as a high-performance modular Rust workspace:

```text
HiveKernel/
├── crates/
│   ├── hive-core/       # Core types, on-disk keystore (0600), Ed25519 receipts, line-level auditor
│   ├── hive-p2p/        # Asynchronous TCP node server/client, RFQ auction matcher & wire protocol
│   ├── hive-escrow/     # Mathematical fraud-proof verifier, optimistic challenge window, ledger
│   └── hive-cli/        # Interactive CLI, standalone daemon runner, live file auditor, simulation
├── contracts/           # EVM Solidity smart contracts for on-chain non-custodial escrow
│   ├── HiveEscrow.sol   # Core escrow and dispute resolution contract
│   ├── test/            # Foundry Solidity unit and invariant tests
│   └── script/          # Foundry deployment scripts (Sepolia / Base / Anvil)
├── foundry.toml         # Foundry workspace configuration
└── tests/               # End-to-end integration and adversarial dispute test suites
```

### 1. Cryptographic Task Receipt (`TaskReceipt`)
Every task completed by a Worker node is sealed with an Ed25519 signature over a deterministic execution digest:
$$\text{Digest} = \text{SHA256}(\text{TaskID} \parallel \text{DelegatorPubKey} \parallel \text{PromptHash} \parallel \text{OutputHash} \parallel \text{Timestamp})$$

### 2. Deterministic Verification & Fraud Proofs
- **Zero Mock Markers**: The Validator independently re-executes the deterministic analysis kernel over the input code.
- If the Worker alters findings, inflates scores, or forges receipts, the Validator generates a cryptographic `FraudProof` with exact byte-level mismatch evidence, triggering automatic slashing.

## 🚀 Getting Started

### Prerequisites
- [Rust](https://www.rust-lang.org/) (version 1.80+)
- [Foundry](https://getfoundry.sh/) (`forge`, `anvil`, `cast`)

### Installation & Build

```bash
# Clone the repository
git clone https://github.com/Webghost01-NG/HiveKernel.git
cd HiveKernel

# Build the entire workspace
cargo build --release
```

## 🧪 CLI Commands & Live Swarm Usage

### 1. Live Multi-Agent Swarm Simulation
Run the end-to-end swarm lifecycle on a real contract file or built-in payload:

```bash
# Run swarm audit simulation
cargo run -p hive-cli -- run-swarm --bounty 180

# Run swarm audit on any custom local file
cargo run -p hive-cli -- run-swarm --file ./contracts/HiveEscrow.sol --bounty 250
```

### 2. Adversarial Dispute & Fraud Detection
Simulate a rogue worker attempting to forge an audit report on vulnerable code:

```bash
cargo run -p hive-cli -- simulate-dispute --bounty 220
```

### 3. Direct File Static Analysis
Instantly audit any Solidity or Rust source file with line numbers and recommendations:

```bash
cargo run -p hive-cli -- audit --file ./contracts/HiveEscrow.sol
```

### 4. Start Standalone P2P Swarm Daemons
Run agents as independent TCP network daemons:

```bash
# Start Worker Node on port 9101
cargo run -p hive-cli -- daemon --role worker --port 9101

# Start Validator Node on port 9102
cargo run -p hive-cli -- daemon --role validator --port 9102
```

### 5. Generate Agent Keystore
Generate a persistent, encrypted Ed25519 keypair:

```bash
cargo run -p hive-cli -- keygen --name worker_beta --out-dir ./keystore
```
